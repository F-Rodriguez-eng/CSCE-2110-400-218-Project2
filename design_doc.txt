2. CAMPUS GRAPH - MICHAEL
CampusGraph uses vector<string> buildings, vector<vector<int>> neighbors,
and int edgeCount. Building names are vertices; walkways are undirected,
unweighted edges. For each connection A|B, the graph adds B to A's neighbor
list and A to B's, but counts the edge only once. An adjacency list grows
dynamically, avoids unused matrix space, and preserves neighbor insertion
order, which the grader uses for BFS traversal and shortest-path ties.

loadBuildings() and loadConnections() read complete text lines, ignore blank
and comment lines, trim outer whitespace, and report malformed records,
duplicates, self-connections, and unknown buildings by file and line number.
Building matching ignores capitalization; original accepted spelling is
preserved. TextHandler.h supplies trimmer(), split(), and eqIgnCase().

displayGraph() prints each building and its neighbors, including
'(no connections)' for an isolated building. displayStatistics() reports
vertex count, undirected edge count, and each building's degree.

bfsReachability() looks up a starting building, uses a queue plus visited
and distance vectors, marks a neighbor visited when enqueuing it, and prints
buildings in BFS order with distances and reachable count. Unknown starts
are rejected; isolated starts reach only themselves.

Final graph features already defined in CampusGraph: shortestPath() uses
BFS parents to reconstruct a route with the fewest edges, while
connectivityReport() finds highest degrees, isolated vertices, and the
number of components using repeated BFS. Both still need Final menu wiring.
